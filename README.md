# 📸 ATIK — Photographer & Designer

**A Visual Storytelling Experience | Personal Photography & Creative Design Portfolio**

Welcome to **ATIK.**, a premium personal portfolio website for **MD. Atiqul Islam (Atik)** — Photographer, Visual Storyteller, and Creative Designer.

This project showcases photography, creativity, and personal branding through a cinematic dark editorial design. Built with pure HTML5 and CSS3, it delivers a modern, responsive, and visually immersive experience without requiring JavaScript or any build tools.

---

## ✨ Features

- **Cinematic Hero Section** — Full-screen photography background with bold typography and an elegant introduction.
- **Modern Navigation** — Minimal navigation bar with a native HTML Popover profile menu.
- **Personal Introduction** — A dedicated section presenting the photographer and creative vision.
- **Photography Gallery** — Horizontally scrolling image collections with elegant hover effects.
- **Editorial Quote Section** — Cinematic background with inspirational photography quotes.
- **Creative Philosophy** — Three creative pillars: Observe, Create, and Remember.
- **Contact Section** — Direct email connection with a stylish call-to-action.
- **Responsive Design** — Optimized layouts for desktop, tablet, and mobile devices.
- **CSS Animations** — Smooth transitions, image effects, and scroll-driven animations.
- **Accessibility** — Semantic HTML and reduced-motion support.

## 🚀 Getting Started

No installation or additional dependencies are required.

### Option 1: Open Directly

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. View the website in a modern browser.

### Option 2: Run with Python

Open your terminal inside the project directory:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

### Option 3: VS Code Live Server

1. Open the project in Visual Studio Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 🖼️ Customization

Make the portfolio your own by updating the following:

| What to Customize | File / Location |
|---|---|
| Website title and SEO | `index.html` |
| Hero introduction | `.hero-content` |
| Profile information | `#about` |
| Photography gallery | `#work` |

| Creative philosophy | `#approach` |
| Contact email | `mailto:` links |
| Social media links | `.social-links` |
| Logo | `images/logo.svg` |
| Images | HTML `<img>` source URLs |
| Colors and typography | CSS `:root` variables |
