# 📸 ATIK — Photographer & Designer

**A Visual Storytelling Experience | Personal Photography & Creative Design Portfolio**

A premium personal portfolio for **MD. Atiqul Islam (Atik)** — photographer, visual storyteller, and creative designer. Built with plain HTML5 and CSS3, featuring a cinematic dark editorial aesthetic.

## ✨ Features

- Full-screen cinematic hero with responsive navigation
- Native HTML Popover profile menu
- Personal introduction and creative philosophy
- Horizontally animated photography gallery
- Editorial quote section
- Contact section with direct email link
- Responsive desktop, tablet, and mobile layouts
- CSS animations, transitions, and hover effects
- Reduced-motion accessibility support

## 🛠️ Technologies

- HTML5
- CSS3 (Grid, Flexbox, animations, media queries)
- Native HTML Popover API
- Google Fonts (DM Sans and Playfair Display)

**No JavaScript, frameworks, package installation, or build tools required.**

## 🚀 Getting Started

### Option 1: Open directly

Open `index.html` in a modern web browser.

### Option 2: Run a local server

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## 🎨 Customization

| What to change | Where |
|---|---|
| Page title and SEO | `<head>` in `index.html` |
| Hero heading and intro | `.hero-content` in `index.html` |
| About content | `#about` section |
| Gallery photos and captions | `#work` section |
| Contact email | `mailto:` links in `index.html` |
| Social links | `.social-links` in `index.html` |
| Logo | `images/logo.svg` |
| Colors and typography | `:root` variables in `style.css` |
| Layout and animations | `style.css` |

Replace the sample Unsplash image URLs with your own photographs before publishing. Update the Instagram link to your actual profile.

## 🌐 Browser Support

Designed for modern browsers. Native popovers and scroll-driven animations may vary in older browser versions; core content remains available.
